# Anjana Wijerathna — Portfolio

Personal portfolio for Anjana Wijerathna, a full-stack developer and BSc (Hons) Computer Science with Software Engineering undergraduate seeking internship opportunities.

## Local development

```sh
npm install
npm run dev
```

## Production build

```sh
npm run build
npm run preview
```

The site is built with Astro, TypeScript, and native CSS. Portfolio content is maintained in `src/data/projects.ts` and the Astro pages under `src/pages`.
